# Notaría Pública No. 95 · Saltillo, Coahuila
**Titular:** Lic. Raúl José Garza de la Peña

Sitio web institucional oficial de alta gama para la Notaría Pública No. 95 en el Distrito Notarial de Saltillo, Coahuila de Zaragoza.

---

## 🏛️ Características y Arquitectura
- **Video Scroll Scrubbing a 60 FPS (Estilo Apple):** Secuencia de fotogramas precargados en memoria y renderizados en `<canvas>` con aceleración GPU e interpolación LERP (cero retraso en decodificación).
- **Efecto Parallax de Fondo Inmóvil (Ventana Pura por GPU):** Fondos fotorrealistas de alta gama fijados nativamente con soporte para desktop y móviles.
- **Portafolio de Servicios Dividido:**
  - *Parte 1: Patrimonio Familiar e Inmuebles* (Compraventas, Escrituración, Testamentos, Sucesiones, Donaciones, Cancelación de Hipotecas).
  - *Parte 2: Empresas, Sociedades y Fe Pública* (Constitución de Sociedades, Poderes, Protocolizaciones, Fe de Hechos, Ratificación de Firmas, Blindaje Corporativo).
- **Fichas Interactivas con Requisitos Legales:** Modal dinámico con requisitos documentales específicos para cada trámite y enlace directo de consulta por WhatsApp.
- **Formulario Notarial y Mapa Interactivo:** Cotización de trámites, aviso de privacidad integral y ubicación en Saltillo.
- **Compatibilidad Total:** Funciona de manera autónoma en servidor local, GitHub Pages o abriendo directamente el archivo HTML sin dependencias de compilación.

---

## 📁 Estructura del Proyecto
- `index.html`: Aplicación web completa y autónoma.
- `*.mp4`: Videos institucionales de alta definición (versiones desktop y móvil).
- `*.jpg`: Fondos fotográficos y texturas de alta gama.
- `frames_hero/`, `frames_hero_mobile/`, `frames_1/`, `frames_11/`, `frames_2/`, `frames_22/`: Secuencias de fotogramas para animación a 60 FPS.
